## 📝 Project Overview
**FLOW** is an Android task management and team collaboration app designed for **remote teams and offices**.  

It helps teams manage tasks efficiently by allowing:
- Creating teams and adding members  
- Assigning tasks with deadlines  
- Tracking task progress and completion  
- Integrated one-to-one chat between team heads and members  

The goal is to **increase productivity and communication** for remote work environments.

---

## ✨ Features
- **Team Management:** Create teams, add/remove members  
- **Task Assignment:** Assign tasks to members with deadlines  
- **Progress Tracking:** Members can update task completion status  
- **Real-Time Chat:** Team heads and members can chat privately  
- **Deadline Notifications:** Keep track of pending tasks  
- **Simple & Intuitive UI:** Built for smooth Android experience


---

## 🛠️ Tech Stack
- **Frontend:** Android Studio (Java/Kotlin)  
- **Backend:** PHP  
- **Database:** MySQL  
- **Server:** XAMPP (Apache + MySQL)  
- **Version Control:** Git & GitHub

---

## 🏗️ Architecture
- Android app sends requests to **PHP APIs hosted on XAMPP**  
- MySQL stores **teams, members, tasks, and chat messages**  
- App retrieves data and updates in real-time
